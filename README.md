## About

This repository contains a complete reference of all commands covered in the **LPIC-1 Linux certification** exam, with descriptions in **Persian (Farsi)**.

The file has been carefully organized by exam topic sections (101.x through 110.x), covering everything from hardware configuration and boot management to networking, security, and encryption.
